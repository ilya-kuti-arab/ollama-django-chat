## ✨ Features

- 💬 **Real-time Chat** - Seamless conversation with Ollama AI models
- 🎨 **Modern UI** - Beautiful, responsive design with smooth animations
- 🔄 **Dynamic Model Switching** - Change models during active conversations
- 📋 **Auto Model Discovery** - Automatically detects installed Ollama models
- ⚡ **Fast Responses** - Optimized API calls for minimal latency
- 🎯 **Error Handling** - Comprehensive error management and user feedback
- 📱 **Mobile Responsive** - Works perfectly on all devices
- 🎭 **Multiple Model Support** - Compatible with all Ollama models (Llama2, Mistral, CodeLlama, etc.)
- 🔒 **Local Processing** - All data stays on your machine, no cloud dependency

## 📋 Prerequisites

Before you begin, ensure you have the following installed:

- **Python** 3.8 or higher
- **Django** 5.0 or higher
- **Ollama** (latest version)
- **Git** (optional, for cloning)
- **pip** (Python package manager)
